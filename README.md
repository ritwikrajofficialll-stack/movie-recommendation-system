# 🎬 Movie Recommendation System

A beginner-friendly Python project that recommends movies based on the user's **age** and **preferred genre**.

## 📌 About the Project

This project takes three inputs from the user:

* Name
* Age
* Genre

Based on the user's age group and selected genre, the program displays a list of recommended movies.

The project is built using basic Python concepts such as:

* `input()`
* Variables
* Data types
* Conditional statements
* `if`, `elif`, and `else`
* Logical operators
* String methods

## 🚀 How It Works

1. The user enters their name.
2. The user enters their age.
3. The user selects a movie genre.
4. The program checks the age and genre.
5. Suitable movie recommendations are displayed.

### Supported Genres

* Horror
* Comedy
* Action
* Historical
* Thriller

## 🛠️ Technologies Used

* Python

## ▶️ How to Run

Make sure Python is installed on your computer.

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/movie-recommendation-system.git
```

Open the project folder:

```bash
cd movie-recommendation-system
```

Run the program:

```bash
python Movie_recomdation_system.py
```
